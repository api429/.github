### Open-source tools for surviving AI API rate limits

We build **API429**, an AI API gateway named after the error everyone hates. Here we share small, provider-agnostic tools for handling `429`s, retries and fallbacks with any OpenAI-compatible API.

### Start here

| Repository | What it does |
|---|---|
| [**429-survival-kit**](https://github.com/api429/429-survival-kit) | Tell rate limits, quota caps and overloads apart. Backoff with jitter, retry budgets, fallback models. Works with OpenAI, llama.cpp server, vLLM, Ollama and other gateways. MIT |

### About API429

- One OpenAI-compatible key and one balance for GPT, Claude, Gemini, Grok, plus image, video and voice models
- Switching models is one `model` string; base URL: `https://gateway.api429.com/v1`
- Public per-model prices, up to 70% less than standard API rates on selected models (see the site for current prices and the date they were checked)
- We can't make provider limits disappear, and nobody honestly can. We help fewer of your jobs die from them
